HOW TO OPEN
- Extract the ZIP file.
- Open index.html in Chrome, Edge, Safari or Firefox.
- Touch/click the envelope to begin the invitation and music.

HOW TO PUBLISH
- Upload index.html, styles.css, app.js and the complete assets folder
  together to any static website hosting service.
- Do not change the assets folder name or file paths unless the matching
  references in the code are also updated.

IMPORTANT
- Browsers allow music only after a visitor taps/clicks the envelope.
- Keep all source files and the assets folder together.
- The package contains no private deployment credential or access token.
